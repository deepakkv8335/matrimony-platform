# WC Matrimony

An MVP (Minimum Viable Product) of a modern matrimony platform built to explore user authentication, profile management, and responsive web application development using JavaScript and Supabase.

> This project is currently under active development.

## Live Demo

🌐 **Website:** https://wcmatrimony.pages.dev

## Current MVP Features

- User authentication with Supabase Auth
- Profile creation and management
- Responsive interface for mobile and desktop
- Dynamic JavaScript interactions
- Cloudflare Pages deployment
- Git-based development workflow

## Tech Stack

| Category | Technology |
|----------|------------|
| **Frontend** | HTML5, CSS3, JavaScript (ES6) |
| **Backend Services** | Supabase |
| **Version Control** | Git, GitHub |
| **Deployment** | Cloudflare Pages |

## Local Setup

1. Clone the repository.

```bash
git clone https://github.com/wcmatrimony/main-website.git
cd main-website
```

2. Open `index.html` directly, or run the project with **Live Server** in VS Code.
